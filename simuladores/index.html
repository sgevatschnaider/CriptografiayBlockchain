Secuencia pedagógica

  1. Predecir: anticipar el resultado antes de ejecutar.
  2. Experimentar: cambiar una sola variable por vez.
  3. Explicar: relacionar el resultado con el objetivo de seguridad.
  4. Atacar: identificar el supuesto que permite quebrar el modelo.
  5. Transferir: conectar la observación con un sistema real.

Para estudiantes

Cada laboratorio contiene conceptos, controles, métricas, retroalimentación, advertencias de alcance y un desafío integrador. Se recomienda registrar hipótesis y conclusiones en una bitácora.
