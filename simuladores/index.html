Laboratorios interactivos de criptografía

Ocho experiencias autónomas para experimentar con cifrados, estructuras matemáticas, primitivas modernas, esteganografía, blockchain, privacidad, transición poscuántica y seguridad de implementación.

HTML + CSS + JavaScriptSin instalaciónCompatible con GitHub PagesActividades y desafíos
Módulo 1Criptografía clásica y criptoanálisis

César, Vigenère, frecuencias, fuerza bruta y comparación entre sustitución y clave repetida.

Módulo 2Fundamentos matemáticos

Aritmética modular, algoritmo de Euclides, inversos, Diffie–Hellman didáctico y entropía.

Módulo 3Criptografía moderna

Efecto avalancha, AES-GCM, derivación de claves y firmas digitales con Web Crypto.

Módulo 4Esteganografía

Ocultamiento LSB en imágenes, capacidad, extracción, distorsión y estegoanálisis básico.

Módulo 5Criptografía y blockchain

Bloques enlazados, minería, manipulación, validación y árboles de Merkle.

Módulo 6Protocolos y privacidad

Secret sharing, compromisos criptográficos e identificación de Schnorr simplificada.

Módulo 7Poscuántica y cuántica

Shor, Grover, BB84, inventario criptográfico y estrategia de migración.

Módulo 8Seguridad aplicada

Reutilización de nonces, entropía de contraseñas, modelado de amenazas y ciclo de vida de claves.

Metodología recomendada

  1. Predecir: formular qué debería ocurrir antes de ejecutar la simulación.
  2. Experimentar: modificar una sola variable y observar el resultado.
  3. Explicar: relacionar el comportamiento con el objetivo de seguridad.
  4. Atacar: explorar el límite, el error o el supuesto que rompe el sistema.
  5. Transferir: vincular el hallazgo con un protocolo o caso real.

Para estudiantes

Cada laboratorio incluye conceptos, controles, métricas, preguntas de reflexión y una advertencia de alcance. Se recomienda registrar capturas y conclusiones en una bitácora.

Para docentes

La suite puede utilizarse como demostración, práctica guiada, trabajo grupal o evaluación oral. La guía docente propone objetivos, tiempos y preguntas por módulo.
