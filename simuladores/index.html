Secuencia pedagógica

  1. Predecir: anticipar el resultado.
  2. Experimentar: cambiar una variable por vez.
  3. Explicar: relacionar observación y objetivo de seguridad.
  4. Atacar: identificar el supuesto débil.
  5. Transferir: conectar con un sistema real.
