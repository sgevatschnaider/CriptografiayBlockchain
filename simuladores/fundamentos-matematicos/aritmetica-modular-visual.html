División euclídea: grupos completos y resto

Teorema de la división. Para todo entero x y todo n > 0 existen únicos enteros q y r tales que x = qn + r, con 0 ≤ r < n.
Segunda representación

Recta numérica y clases de congruencia

Dos enteros son congruentes módulo n cuando su diferencia es múltiplo de n. Todos los valores resaltados caen en la misma posición del reloj.

Propiedades

Laboratorio de operaciones

Reducir después de operar o reducir antes produce el mismo resultado para suma, resta y multiplicación.
Invariantes

Reglas que preservan el resto

Si a ≡ a′ (mod n) y b ≡ b′ (mod n), entonces:

a + b ≡ a′ + b′ (mod n)
a − b ≡ a′ − b′ (mod n)
ab ≡ a′b′ (mod n)

Estas compatibilidades permiten operar directamente con clases de residuos y son la base algebraica de muchos criptosistemas.
