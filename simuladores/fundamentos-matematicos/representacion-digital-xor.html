Representar no es cifrar

Los mismos bits pueden escribirse en distintas bases. Cambiar la representación no agrega secreto.

1

Símbolo

Unicode asigna un punto de código a cada carácter, por ejemplo A → U+0041.

2

Codificación

UTF-8 transforma los puntos de código en una secuencia concreta de bytes.

3

Representación

Binario, decimal y hexadecimal muestran los mismos valores con distintas bases.

4

Transformación

Un cifrado opera sobre esos bytes con una clave para producir un criptograma.

Hexadecimal y Base64 Son representaciones reversibles y públicas. No necesitan una clave.
Cifrado Busca confidencialidad. Requiere un algoritmo, una clave y supuestos de seguridad.

XOR no aporta seguridad por sí solo.

La protección depende de cómo se genera y utiliza K. Si se reutiliza el mismo flujo, dos criptogramas revelan C₁ ⊕ C₂ = M₁ ⊕ M₂. En sistemas reales se emplean construcciones revisadas, claves secretas y nonces que no se repiten.

El orden de los bytes

Una secuencia de cuatro bytes puede representar números distintos según cuál se considere primero.

Big-endian
— El byte más significativo aparece primero.
Little-endian
— El byte menos significativo aparece primero.
Los protocolos criptográficos especifican el orden exacto para que todos interpreten los mismos bytes.

Conceptos para conservar

Glosario esencial

Bit

Unidad binaria con dos estados posibles: 0 o 1.

Byte

Grupo de ocho bits. Puede representar valores entre 0 y 255.

Unicode

Estándar que asigna puntos de código a caracteres de múltiples sistemas de escritura.

UTF-8

Codificación variable que representa cada punto de código Unicode mediante uno a cuatro bytes.

Hexadecimal

Sistema en base 16. Dos dígitos hexadecimales representan exactamente un byte.

Base64

Codificación textual de datos binarios. Facilita transporte y almacenamiento, pero no cifra.

XOR

Operación bit a bit que vale 1 cuando las entradas son diferentes. Aplicar dos veces la misma K recupera M.

Endianness

Convención que establece el orden con el que se interpretan los bytes de un valor de varias posiciones.

Puente hacia la criptografía moderna

Estos fundamentos aparecen en todo el recorrido

AES procesa bloques de bytes, ChaCha20 combina datos y keystream mediante XOR, las funciones hash reciben secuencias de bits y los protocolos definen formatos binarios precisos. Comprender la representación permite distinguir qué pertenece al mensaje, qué pertenece al formato y qué aporta realmente seguridad.
