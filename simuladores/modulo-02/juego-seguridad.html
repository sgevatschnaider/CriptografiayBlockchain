Alcance del modelo

Aporta: vuelve visible la lógica de un juego, una consulta al oráculo, un bit secreto y una ventaja medible.

Simplifica: la «aleatorización fresca» usa pads independientes para mostrar el principio. Un esquema real seguro usa una clave persistente con nonces y una construcción analizada.

Desafío de transferencia

Explicá por qué un cifrado determinista puede filtrar información incluso si el adversario nunca recupera la clave: ¿qué aprende al cifrar dos veces el mismo mensaje?

Ver orientación

Si iguales entradas bajo la misma clave producen iguales salidas, el adversario puede reconocer repeticiones o verificar hipótesis mediante consultas. La seguridad CPA requiere aleatorización efectiva o nonces correctamente administrados.
