Las cinco ruedas χ avanzan regularmente. Las cinco ψ avanzan juntas de forma intermitente, bajo control de μ61 y μ37. Los patrones utilizados aquí son didácticos y reproducibles; las configuraciones históricas cambiaban operativamente.

Idea central

Lorenz no sustituye directamente letras como Enigma. Cada carácter llega como cinco bits paralelos y la máquina combina cada canal con un bit de clave mediante suma módulo 2.

Qué hacía Colossus
Colossus no imprimía automáticamente todo el texto claro. Leía cinta perforada, generaba patrones de ruedas, evaluaba funciones booleanas y contaba resultados para localizar ajustes prometedores, especialmente de las ruedas χ.
