# Módulo 9 · Bitcoin

Módulo independiente incorporado sin modificar el contenido del Módulo 5 de Blockchain.

- cuatro presentaciones de 16 diapositivas cada una, sin notas del orador;
- visor local completo con navegación, miniaturas, teclado, reproducción automática y pantalla completa;

- glosario interactivo de 94 términos;
- cuestionario de 20 preguntas con respuestas desarrolladas.
