Microscopio de planos de bits y estegoanálisis visual

Una imagen puede parecer intacta y, sin embargo, haber cambiado en miles de bits. Este laboratorio permite observar esos cambios, comparar planos binarios, amplificar diferencias y medir señales simples que un analista puede utilizar para formular una hipótesis de ocultamiento.

Principio

“No lo veo” no equivale a “no deja huella”

El sistema visual humano es tolerante a pequeñas variaciones de intensidad. Por eso un cambio de ±1 en un canal RGB suele ser imperceptible.
El estegoanálisis cambia la pregunta: no busca necesariamente ver el mensaje, sino determinar si el objeto se comporta como una imagen normal o como una imagen modificada.

Estación 1

Explorador de planos de bits

Cada canal RGB tiene 8 bits. El plano 0 contiene los LSB; el plano 7 contiene los MSB. Los planos bajos suelen parecer más ruidosos y son candidatos naturales para ocultamiento.

Estación 2

Mapa amplificado de diferencias

La imagen de diferencias multiplica los cambios para volverlos visibles. Blanco significa “sin cambio”; los tonos intensos indican qué canal se alteró.

El índice combina señales simples y no representa un clasificador forense real.
Regla profesional: una sola señal rara no basta. El estegoanálisis serio combina características, modelos de amenaza, comparación con distribuciones de referencia y validación estadística.

Preguntas para interpretar

  1. ¿En qué plano aparecen más cambios?
  2. ¿La imagen sospechosa sigue pareciendo igual?
  3. ¿Qué ocurre con la paridad al aumentar la densidad?
  4. ¿El χ² sube o baja?
  5. ¿Por qué ninguna métrica aislada demuestra esteganografía?

Conexión con el material

El módulo introduce detección estructural de LSB, ataques estadísticos y estegoanálisis mediante machine learning. Este laboratorio se concentra en la intuición visual y estadística previa a esos métodos más avanzados.
