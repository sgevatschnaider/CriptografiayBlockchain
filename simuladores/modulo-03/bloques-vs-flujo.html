Cifrador por bloques

AES transforma bloques de 128 bits. Un modo como CTR o GCM decide cómo procesar una secuencia de bloques y cómo usar un nonce.

El padding no autentica. CBC puede necesitar PKCS#7, pero todavía requiere una construcción de autenticación separada o un modo AEAD.

Cifrador por flujo

ChaCha20 produce un keystream a partir de clave, nonce y contador. Se combina con el mensaje mediante XOR y normalmente se usa con Poly1305 para autenticar.

El flujo no es el problema. La falla aparece al repetir clave + nonce y, por lo tanto, repetir el keystream.
