Construir, observar y verificar AES

Dos niveles separados: una implementación educativa exacta de AES-128 para inspeccionar estado, subclaves y rondas; y Web Crypto para ejecutar AES-GCM real, autenticar datos y rechazar alteraciones.

Arquitectura del recurso

Modelo transparente y primitiva real

Nivel A · AES-128 inspeccionable

Implementa SubBytes, ShiftRows, MixColumns, AddRoundKey, expansión de clave y descifrado para mostrar cada estado. Se valida con el vector conocido de FIPS 197.

Nivel B · AES-GCM de plataforma

Usa crypto.subtle para cifrar y descifrar. Las claves no son exportadas por el laboratorio y los datos permanecen en este navegador.

Regla metodológica

La implementación inspeccionable se utiliza para estudiar AES-128 sobre un bloque. Para operaciones aplicadas se delega el cifrado a Web Crypto; no se presenta el código educativo como biblioteca de producción.

Decisión de aceptación

Web Crypto no entrega el texto si la verificación falla. Ciphertext, nonce, AAD y tag forman una unidad lógica: alterar cualquiera de los componentes autenticados produce rechazo.
