Regla de diseño

No se elige solamente un algoritmo. Se eligen una primitiva, un modo o construcción, parámetros, nonces, autenticación, derivación, almacenamiento, rotación y un modelo de amenaza.

Para sistemas nuevos, el recorrido profesional prioriza APIs de alto nivel y cifrado autenticado, por ejemplo AES-GCM o ChaCha20-Poly1305.
