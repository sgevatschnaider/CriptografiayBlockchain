Metodología de trabajo

  1. Predecir: formular qué debería ocurrir antes de ejecutar.
  2. Experimentar: modificar una variable y observar el resultado.
  3. Interpretar: relacionar la métrica con la propiedad de seguridad.
  4. Atacar: explorar el supuesto, error o límite que rompe el mecanismo.
  5. Transferir: vincular el hallazgo con un protocolo o sistema real.

Alcance técnico

Las primitivas modernas utilizan Web Crypto cuando corresponde. Los algoritmos históricos, parámetros pequeños y protocolos simplificados se presentan únicamente con fines educativos.
